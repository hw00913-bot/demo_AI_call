四. 功能说明

1. 系统管理-业务场景-新增大众通信任务场景

1）功能名称： 新增大众通信业务场景

2）交互说明： 点击“新增业务场景”，智能平台选择“大众通信”后，仅展示大众通信任务 ID（uuid）。重呼、并发、呼叫时间等任务策略不在中台重复配置。

3）数据来源： 大众通信官方 API v2 字段口径、AI 智能外呼中台配置。

4）逻辑说明： 先在大众通信 SaaS 创建任务并完成重呼、并发、呼叫时间、线路等策略配置，再将必填 uuid 粘贴到中台完成关联。

2. 外呼场景-外呼列表

1）功能名称： 大众通信外呼任务卡片

2）交互说明： 外呼列表按关联任务 ID 展示大众通信任务卡片，操作区与一知、中科金保持“查看、编辑、更多”一致结构；大众任务的编辑按钮以及更多菜单中的删除、暂停、终止、启动均置灰不可点击。点击“查看”后，任务详情继续使用相同抽屉、Tab 和单列信息行。

3）数据来源： 大众通信 GET /agent-api/new/user/{user_id}/task/{task_id}/edit 返回数据、AI 智能外呼中台 Mock 数据。

4）逻辑说明： 远端任务状态 1/2/3 分别对应暂停中/执行中/等待执行；任务详情统一取新版 2.0 外呼任务编辑接口的 new_task_extra 数据，并使用 3.0 大模型相关接口口径，不再兼容旧版 2.0 的 task_extras。页面按中科金、一知的交互结构聚合为单列只读信息，空字段显示“-”，修改仍在大众通信 SaaS 完成。

3. 外呼结果-通话记录

1）功能名称： 大众通信通话记录

2）交互说明： 通话记录支持按平台和关联任务 ID 筛选，默认视图将大众通信通话记录置顶展示。大众通信记录将 0–12 通话状态码转换为中文；点击详情后直接展示录音、通话文本、外呼结果和详细信息，不展示顶部回调或详情获取状态提示。

3）数据来源： 大众通信通话结束回调、通话详情接口口径、AI 智能外呼中台 Mock 数据。

4）逻辑说明： 通话记录列表默认优先将大众通信数据置顶呈现（用户主动点击表头列排序时按指定列升降序排列）。大众通信收到通话结束回调后，才使用回调 callid 生成通话记录，并将同值作为 recordid 查询通话详情。没有回调时列表中不产生记录，详情页也不存在等待回调状态；其他平台保持原有逻辑。

4. 外呼结果-线索记录

1）功能名称： 大众通信线索意向展示

2）交互说明： 线索记录不新增平台筛选，大众通信线索与其他平台数据并列展示。

3）数据来源： 大众通信意向结果、通话结束回调、通话详情 componet/component 自定义组件、百炼智能体、AI 智能外呼中台 Mock 数据。

4）逻辑说明： 大众通信字段 intention_results 为 1–6 时分别显示 A–F；空值或超出范围时显示“未评级”。最后回访记录对应通话总结：优先取通话详情 componet/component 自定义组件中的总结，缺失时取百炼智能体总结。大众线索的客户详细标签取通话详情 componet/component 返回且有值的非总结自定义字段名称；线索内的通话详情外呼结果和详细信息与通话记录页保持同一套字段顺序和取值口径。
