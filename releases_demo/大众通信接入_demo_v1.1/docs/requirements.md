# 大众通信接入 Demo v1.1 需求与验收说明

> 交付版本：v1.1  
> 口径日期：2026-07-24  
> 本文档是面向 PM 和演示验收的说明页；loop 的运行状态仍以 `config/workflow.json` 和 `memory/` 下的阶段产物为准。

## 1. 项目目标

在保留一知科技、中科金智能等已有平台能力的前提下，并列接入“大众通信”，演示其外呼任务配置、任务状态、通话结果、意向等级、标签映射与统计计费数据在智能外呼中台中的完整落点。

## 2. 目标用户与核心路径

- 外呼中台超管：配置大众通信任务字段，维护 A–F 意向标签与本地标准标签的手动映射。
- 话务运营人员：查看外呼任务状态、通话记录、线索意向以及通话/计费统计。
- 核心路径：新增大众通信场景 → 查看外呼任务 → 筛选通话记录 → 查看线索意向 → 手动维护标签映射 → 核对通话与计费统计。

## 4. 字段与数据口径

- 任务关联：中台填写必填 `uuid`、模型类型（大模型/小模型）和账号，用于关联已在大众通信 SaaS 创建的任务和保证中台业务场景表字段一致性。
- SaaS 配置：重呼、并发、呼叫时间、任务类型、线路和弹号顺序均在大众通信 SaaS 中维护；中台可展示远端返回的任务信息，但不重复配置。
- 模型与账号：模型类型和账号字段保留是为了中台表字段一致性，不是用于控制外呼接口版本。
- 外呼任务接口：统一使用新版 2.0 外呼任务编辑接口，任务详情只读取 `new_task_extra`；不再兼容旧版 2.0 `task_extras`。
- 大模型接口：统一按 3.0 大模型接口口径展示和说明。
- 任务状态：`status` 为 `1=暂停中`、`2=执行中`、`3=等待执行`。
- 计费统计主列表按截图保持精简展示：筛选区仅保留计费日期和租户名称，列表仅展示计费日期、租户名称、计费时长和详情；`billingType` 是中台派生归类字段，不冒充大众通信官方 API 字段，也不在主列表展示。
- 通话详情：录音地址取通话结束回调中的录音链接；通话文本取通话详情 `records`；外呼小结优先取详情 `componet/component` 自定义组件总结，缺失时取百炼智能体总结；通话标签取有值的非总结自定义组件字段名称。

## 7. 当前验证结论

截至 2026-07-24，v1.1 原型回归结论为通过：13 条大众通信状态记录覆盖 `0–12`；大众任务详情按新版 2.0 外呼任务编辑接口 `new_task_extra` 和 3.0 大模型接口口径只读展示；通话记录按回调 `callid` 生成并以 `recordid=callid` 查询详情；录音、通话文本、外呼小结、详细信息和线索最后回访记录已对齐；通话统计与计费统计均按截图精简字段展示；呼叫名单手动导入功能已实现（大众通信限 100 条/次）；业务场景表单保留模型类型和账号配置；标注覆盖 8 个页面共 42 个标注点；交付页、说明文档和流程图集资源引用已检查。详细操作与证据见 `memory/verification-log.md`；该结论不代表真实接口联调通过。
