# 项目记忆 (v1.1)

> 工作流冻结基线的当前迭代：`v1.0`；本次用户交付版本：`v1.1`。

本项目处于当前迭代 v1.1。本轮从 `01_WIKI_LLM` 只读消费 2026-07-14 的大众通信项目页与概念对齐页，把官方 API v2 口径同步到原型。

## 产品目标
本迭代的产品目标为：在保留底座已有平台（一知、中科金等）的基础上，并列新增并集成“大众通信”平台，演示其特定的呼叫任务配置、13个通话状态码对应的中文解析展示，以及线索记录中的 A-F 意向等级。同时，演示在超级管理员模式下，手动对大众通信的意向等级进行配置及映射。

## 目标用户
- **外呼中台超管**：负责配置平台接入参数、供应商信息及管理本地意向标签的手动映射与排序。
- **话务运营人员**：负责配置与管理外呼场景、任务并监督通话与线索统计明细。

## 核心页面列表
1. **业务场景管理页 (`sys-scene`)**：大众通信只关联任务 uuid；重呼、并发、呼叫时间等在大众通信 SaaS 配置。
2. **通话记录页 (`result-records`)**：支持按平台筛选并展示包含大众通信 13 种通话状态的明细记录。
3. **线索记录页 (`result-clue`)**：并列展示各平台线索，大众通信线索意向等级显示为 A-F。
4. **意向标签页 (`sys-tags`)**：大众通信标签不从接口读取，由管理员在中台手工维护标签池及本地标签映射。
5. **外呼列表 (`scene-list`)**：按关联 uuid 展示大众任务状态、名单和进度，不提供中台侧任务操作。
6. **通话统计 (`report-call`)**：支持按大众通信平台和关联任务 ID 筛选同步记录的汇总结果。
7. **计费统计 (`report-billing`)**：展示中台通话记录的派生汇总，实际账单以大众通信 SaaS 为准。

## 核心用户路径
- **路径一：关联大众通信任务**：先在大众通信 SaaS 完成重呼、并发、呼叫时间等任务配置 -> 超管进入业务场景页 -> 选择“大众通信” -> 填写 uuid -> 保存并关联任务。
- **路径二：通话结果筛选与映射**：运营人员进入通话记录页 -> 筛选平台“大众通信” -> 查看大众通信的 13 种通话状态中文解析 -> 进入线索记录查看 A-F 等级意向数据。
- **路径三：意向标签手动维护**：超管进入标签管理 -> 点击大众通信节点 -> 在工作区中手动将 A-F 映射到本地标准标签。

## 主要数据对象
- **外呼场景任务**：中台仅以 uuid 关联并读取任务状态、名单进度和结果，远端任务策略不在中台维护。
- **通话记录**：挂载大众通信 13 种通话状态码的实际数据行。
- **线索记录**：包含特定意向等级数据，空值显示为未评级。
