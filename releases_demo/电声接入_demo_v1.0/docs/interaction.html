四. 功能说明

1. 系统管理-业务场景-新增电声场景

1）功能名称： 新增电声业务场景与呼叫任务配置

2）交互说明： 管理员在新增业务场景抽屉选择“电声”后，页面根据场景类型自动匹配并只读展示机器人名称和编码，同时展示呼叫时段、重呼规则、黑名单校验、自动启动、模型类型和电声账号。点击“确定并生成任务”后按钮进入加载状态，中台先调用电声新增外呼策略接口；接口成功后生成任务并回到场景列表，接口失败则保留抽屉和已填写内容。

3）数据来源： SRC-001、SRC-002、SRC-008；字段对应 FLD-001、FLD-016～FLD-023。

4）逻辑说明： 20260713 接口以 strategyCode 作为外呼任务引用键。提交顺序为：完成前端校验、调用 /strategy/policy/create、校验 code=S0000 及任务标识、写入本地数据。接口失败或响应不完整时不写入业务场景、外呼列表和任务详情；新建任务时不预生成导入批次或执行批次。

2. 外呼场景-外呼列表-详情

1）功能名称： 电声外呼任务卡片与三页签详情

2）交互说明： 用户可按电声平台筛选任务，点击“查看”打开详情抽屉，并在数据概览、呼叫名单、任务详情三个页签间切换。呼叫名单包含已分配、待呼叫、已呼叫、已过滤和呼叫失败五个子页签。

3）数据来源： SRC-003、SRC-004、SRC-008；字段对应 FLD-001～FLD-004、FLD-013、FLD-024、FLD-025。

4）逻辑说明： 线索通过 /lead/batch/async/import 返回 importBatchId 后，中台必须在本地保存导入批次编码，并建立其与本地任务、strategyCode 的关联。isCompleted=false 时保留该批次为“可继续导入”，后续通过本地保存的 importBatchId 继续追加；仅当 isCompleted=true 时才进入执行流程，返回 executeBatchId 后再保存导入批次与执行批次的关联。电声不提供单线索停止，运营只能通过 /execute/batch/stop 停止整个执行批次。

3. 外呼拦截-外呼黑名单

1）功能名称： 中台黑名单与多平台同步管理

2）交互说明： 用户可搜索、新建和编辑分组，按号码、添加类型、平台整体同步状态和添加时间筛选，执行新增、导入、导出、批量移动、同步重试和移除。平台绑定、单平台详情和号码同步明细通过弹窗展示。

3）数据来源： SRC-009 与中台 Mock；字段对应 FLD-026、FLD-027。

4）逻辑说明： 中台分组和号码为业务主数据，一个分组可启用多个已接入平台，每个平台独立维护分组键和同步结果。运营不维护映射表或 JSON；电声适配器生成 groupCode，首次新增号码时自动建组。任一平台删除失败时保留本地拦截。

4. 外呼结果-通话记录

1）功能名称： 电声通话记录与会话详情

2）交互说明： 用户可按号码、场景、状态和平台查询记录，点击详情查看录音卡片、机器人会话文本、外呼小结、百炼外呼结果标签和详细话单字段。本期不展示挂机类型和转人工信息。

3）数据来源： SRC-001、SRC-006、SRC-007；字段对应 FLD-003、FLD-004、FLD-006～FLD-012、FLD-014。

4）逻辑说明： 中台只有一个“通话状态”字段。优先按电声 answerStatus 映射具体状态，子状态缺失或未知时再用 answerMainStatus 兜底；页面不独立展示主、子接听状态。列表和详情均不展示线路类型、数字员工岗位和加微状态；是否重拨在线索回访明细中根据拨打次数派生。

中台任务状态电声策略状态映射与操作说明
进行中statusType=1（启用）电声策略启用时展示为进行中，可执行线索导入及后续呼叫流程。
用户暂停statusType=0（冻结）中台暂停调用 /strategy/policy/status/inactive/update；仅远端成功后更新本地状态。
未开始无直接映射中台本地生命周期状态，不根据 statusType 单独推导。
已终止无直接映射当前电声没有对应任务终止操作接口，不得用停止执行批次替代。
已完成无直接映射由中台根据任务下线索和执行批次是否全部结束判断，冻结不等于完成。

停止执行批次只更新执行批次状态，不修改电声策略 statusType 和中台任务状态。
