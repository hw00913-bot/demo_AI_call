# 项目记忆

## 项目定位

- **项目名称**：电声接入_demo_v1.0
- **当前迭代**：v1.0-电声接入原型
- **创建日期**：2026-07-02
- **类型**：无构建步骤的静态前端原型
- **入口**：`index.html`

## 产品目标

- 展示 AI 语音外呼对接电声平台后的中台前端交互。
- 帮助产品经理及干系人直观评估电声平台接入后的业务场景创建、任务生成、外呼执行和结果核查流程。
- 模拟展示 D05 外呼过滤、D02 通话记录、D06 通话小结的真实回调展示逻辑，以及线索标签归一后的业务结果。

## 目标用户

- **超级管理员**：查看全部租户的任务列表和历史记录。
- **租户管理员**：创建、终止并完整监控本租户的电声外呼任务与名单。
- **业务运营**：查看呼叫名单和通话统计报表。

## 核心页面列表

- **新建业务场景抽屉 (`sys-scene.js`)**：在选择“电声”平台后，配置呼叫任务配置、模型类型和电声账号；按 20260707 新版接口，提交应生成/维护外呼任务 `strategyCode`，后续线索导入和执行批次异步生成实际任务。
- **外呼任务详情查看页 (`scene-list.js`)**：滑出抽屉页展示数据概览（指标及柱状/环形图）、呼叫名单（已分配/待呼叫/已呼叫/已过滤/呼叫失败，待呼叫提供终止呼叫功能）、以及任务详情配置。
- **统计分析-通话统计 (`report-call.js`)**：展示基于电声任务维度的外呼指标及客户量统计。
- **标签管理 (`sys-tags.js`)**：提供系统管理下的供应商标签集与中台标签集配置；默认展示电声平台的意向、加微、重拨及过滤标签，本期不包含转人工标签。
- **外呼结果-通话记录 (`result-records.js`)**：列表呈现通话历史，点击进入详情，展示录音、会话文本、意向结果和外呼小结。
- **外呼结果-线索记录 (`result-clue.js`)**：按客户维度聚合呈现，支持点击回访明细弹窗查阅多次回访明细与详情。

## 核心用户路径

1. 进入系统管理，在业务场景新增“电声”场景，配置呼叫任务配置、模型类型和电声账号，提交后生成或维护外呼任务 `strategyCode`。
2. 在外呼列表中通过新版 `/lead/batch/async/import` 导入号码包，引用已启用的 `strategyCode`，展示导入受理与后续执行结果。
3. 开启任务，号码经 D05 过滤或经外呼后产生接通/未接通，在呼叫名单中呈现不同状态（已过滤名单中分类展示过滤具体原因）。
4. 在通话记录或线索记录中，用户可点击“详情”查阅单次通话的详细信息（录音、文本、意向结果及小结）。

## 主要数据对象

- **外呼任务 (CallStrategy)**：含任务编码、任务名称、模型类型、账号、机器人编码、线索类型映射、呼叫时段、重试配置、黑名单校验、自动启动、创建时间和状态。
- **执行批次 (ExecuteBatch)**：含导入批次号、执行批次号、执行状态、线索数、完成数、拦截数、停止数和起止时间。
- **客户 (Customer)**：含被叫号码、姓名、所属门店 dlrCode、呼叫子状态（301/302/303/205/206）及意向大类（intentionStatus/intentionRank）。
- **过滤记录 (FilterRecord)**：含被叫号码、电声 `BLOCKED` 原始结果、本地通话状态“黑名单过滤”和本地更新时间。

## 交付方式

- 静态项目包，包含 annotations 标注说明。无需依赖 npm 包管理器，通过 `python3 -m http.server 8080` 本地运行。

## 已确认假设

- **假设 1**：在新增业务场景时，前台界面不提供通道选择和加微配置，其逻辑在中后台为隐式关联。
- **假设 2**：在通话记录和详情中，加微状态（`wechatStatus`）仅做只读数据字段呈现（来自回调数据中的 mock 信息），前端不提供加微事件流交互。
- **假设 3**：20260713 话单回调不提供重拨标识；回访明细仅在获得执行批次线索明细时，根据 `attemptCount > 1` 派生“是否重拨”。
- **假设 4**：电声任务 id 不由新建业务场景手工填写；业务场景提交创建外呼任务并维护 `strategyCode`。导入时一个号码生成一个完成态导入批次，并产生对应 `executeBatchId`。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表、标签管理）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 菜单路由配置（唯一路由数据源，由 `js/nav.js` 动态渲染）
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `tools/` — 开发辅助工具脚本
