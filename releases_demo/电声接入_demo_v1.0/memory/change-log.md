# 项目变更记录

## 2026-08-20 精简黑名单号码详情

- 黑名单号码详情弹窗移除“客户名称”和“来源”字段。
- 来源仍作为黑名单主列表字段和底层数据保留，不影响现有筛选与同步逻辑。

## 2026-08-19 手工导入改为一号码一批次

- 移除导入弹窗的新建批次、继续未完成批次和“本次为最后一次导入”配置。
- 上传文案改为每个号码自动生成独立批次且默认完成；导入记录改为展示生成批次数。
- 模拟提交按号码生成一对一的导入批次和执行批次，每个执行批次线索数为 1。

## 2026-08-19 电声拦截状态映射

- 电声 `leadStatus=BLOCKED` 或 `finalCallResult=BLOCKED` 统一映射为本地通话状态“黑名单过滤”。
- 已过滤名单的过滤原因改为展示“黑名单过滤”，不再展示“过滤/拉黑（BLOCKED）”。
- 保留电声原始枚举值；未来接口提供拦截原因后，再扩展“拦截规则”和“线路拦截”的精确映射。
- 用户主动终止产生的本地过滤记录继续展示自身原因，不默认套用 `BLOCKED`。

## 2026-07-20 标签管理改为统一场景配置

- 移除标签管理中的电声“不支持”状态、场景置灰逻辑和“电声支持”列。
- 中台标签集与供应商标签集统一使用场景配置，新增场景在两类配置树中均可维护。
- 电声仅支持新线索和冷线索的限制仅保留在新建业务场景表单。

## 2026-07-20 恢复中台场景配置功能

- 恢复场景配置中的新增、编辑、启停和删除操作，并增加独立的“电声支持”状态列。
- 新增场景默认在中台启用，在电声供应商标签集下默认置灰并标记“不支持”。
- 电声供应商支持范围仍仅包含新线索和冷线索，不因中台新增场景自动扩展。

## 2026-07-20 修正标签场景禁用边界

- 中台标签集恢复督办、服务、回访场景的正常维护能力。
- 电声不支持限制仅作用于供应商标签集下的电声平台，不再影响中台统一标签集。

## 2026-07-20 标签管理场景类型与任务管理对齐

- 标签管理统一展示督办、服务、回访、新线索和冷线索，不再使用保客回访、线索激活、临保邀约等独立枚举。
- 电声仅支持新线索和冷线索；督办、服务、回访显示“不支持”，标签配置和启用操作均禁用。
- 场景配置改为固定枚举，不再允许在标签管理中新增、改名或删除场景类型。

## 2026-07-20 电声场景类型自动匹配机器人

- 新建电声业务场景移除机器人选择控件，改为只读展示场景类型匹配的机器人名称和编码。
- 新线索绑定 `NEW_LEAD` 和 `robot_ds_nissan_001`，冷线索绑定 `COLD_LEAD` 和 `robot_ds_nissan_002`；提交时自动生成 `leadTypeRobotMapping`。
- 场景与机器人映射统一维护在 `config/diansheng-robots.json`，指定场景缺少映射时阻止任务生成。

## 2026-07-20 映射表中台字段中文化
